github 无法链接问题排查

2025 / 07 / 01
Github Net

最近发现在家只要是和github相关的操作都无法正常进行，但网页端访问却没问题。

于是开始着手解决。

解决方案：

  1. 先获取github动态地址，从https://www.ipaddress.com/site/www.github.com获取。
  2. 找到设备的host文件，加入githubIP github.com这行。
  3. 问题解决。
