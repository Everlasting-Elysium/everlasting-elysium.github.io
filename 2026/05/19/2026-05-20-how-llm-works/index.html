大模型是怎么工作的：从字母接龙到理解世界

2026 / 05 / 20
AI 大模型 原理

你有没有想过，ChatGPT 到底是怎么”懂”你说的话的？

它不是一个搜索引擎，也不是一个提前写好答案的数据库。它是一个在海量文字里泡大的模型，学会了一件事：根据前面的内容，猜下一个词是什么。

听起来简单得有点可疑。但这件看似简单的事，做到极致之后，就是 GPT-4。

一、一切从”猜下一个词”开始

大模型的训练目标非常朴素：给你看一段话，让你猜接下来会出现什么词。

“今天天气很好，我决定出去___“

人类会填”散步”、”跑步”、”买菜”，不会填”火箭”或”哭泣”——因为我们对世界有理解，知道什么词在什么语境下合理。

大模型也在做同一件事，只不过它的”理解”来自于读过的几千亿个词。训练时，模型每猜一次，就对比真实答案，然后调整自己的参数，让下次猜得更准。这个过程重复几万亿次之后，模型就慢慢”懂”了语言的规律。

这个任务叫做自回归语言建模，是整个大模型的地基。

二、Token：模型眼里的世界

模型处理的不是字母，也不是词，而是 Token——一种介于字符和词之间的单位。

“I love you” 会被切成 I / love / you 三个 token。但 “unbelievable” 可能会被切成 un / believ / able，因为这样能更高效地覆盖各种词汇。

中文通常一个字或两个字是一个 token。所以你会发现，同样的意思，英文用的 token 比中文少，模型处理起来也快一些。

理解 token 的意义在于：模型每次生成，都是从所有可能的 token 里挑一个概率最高的。它看到的是 token 的序列，预测的也是下一个 token，而不是”下一句话”或者”下一个想法”。

三、Transformer：注意力才是关键

2017 年之前，处理序列数据的主流方法是 RNN（循环神经网络）。它像人读书一样，一个字一个字往后读，但前面读过的内容会随着距离增加而慢慢”遗忘”。

2017 年，谷歌发了一篇论文，叫做《Attention is All You Need》，提出了 Transformer 架构。核心思想是：不按顺序读，而是让每个词同时看所有其他词，自己决定哪些地方值得关注。

这个机制叫 Self-Attention（自注意力）。

举个例子：

“The animal didn’t cross the street because it was too tired.”

这里的 “it” 指的是 “animal” 还是 “street”？

人类一眼就能判断，因为我们知道”疲倦”是动物的属性。Transformer 通过自注意力机制，让 “it” 这个词在计算时自动和 “animal” 建立更强的关联，而不是 “street”。

这种”谁跟谁有关系”的能力，让 Transformer 在理解长文本、处理复杂语义时远超之前的模型。现在所有主流大模型——GPT、Claude、Gemini——底层都是 Transformer。

四、规模才是魔法

有一个现象困扰了研究者很久：当模型参数量超过某个阈值，它突然就会做一些”没教过它”的事——做数学题、写代码、类比推理。

这叫涌现能力（Emergent Abilities）。

没人明确教过 GPT-3 做加减法，但它能做。这背后的原因现在还没有完全搞清楚，但经验规律是：模型越大、数据越多、算力越足，能力就越强，而且是非线性地增强。

这个规律被称为 Scaling Law，是驱动这几年大模型军备竞赛的核心逻辑。OpenAI、Anthropic、Google 烧那么多钱，本质上是在赌：继续堆规模，会有更多涌现能力出现。

五、预训练之后：让模型学会”说人话”

预训练结束后，模型已经很”博学”了——它见过太多文字，什么都知道一点。但它还不擅长”对话”，更不懂什么是有帮助的回答。

这时候需要第二阶段：微调（Fine-tuning）+ RLHF。

RLHF 的全称是 Reinforcement Learning from Human Feedback，人类反馈强化学习。简单说就是：

  1. 让模型生成几个不同的回答
  2. 人类标注员给这些回答排名，哪个更好
  3. 用这些排名训练一个”打分模型”
  4. 再用这个打分模型反过来训练语言模型，让它生成更高分的回答

这一步让模型从”知道很多但说话奇怪”变成”有帮助、无害、诚实”。你现在用的 ChatGPT 和 Claude，都经过了这一步。

六、它真的”懂”吗？

一个无法回避的问题：大模型真的理解语言，还是只是在做精巧的统计匹配？

坦白说，这个问题现在没有定论。

有一派认为，大模型本质上是”随机鹦鹉”，只是在拼接训练数据里的模式，没有真正的理解。另一派认为，理解本身就是一种模式识别，人类大脑也不过如此。

我倾向于一个更务实的观点：它到底”懂不懂”这个哲学问题可以先放一边，重要的是它在很多任务上表现出了类似理解的能力。会不会有幻觉、会不会犯错——当然会，但这不妨碍它在正确使用的场景下，真的很有用。

总结

把整个过程串起来：

  1. 用几千亿词训练模型猜下一个 token，这是预训练
  2. 底层架构是 Transformer，自注意力机制让它理解词与词之间的关系
  3. 规模到一定程度，涌现出意料之外的能力——Scaling Law
  4. 用 RLHF 让模型学会对话，变得有帮助

一个字母接龙的游戏，玩到极致，就成了现在这个样子。
