纹身检测的 Domain Gap：三重 OOD 为什么让所有现成方案全部失效

2026 / 06 / 17
YOLO Computer Vision Domain Gap Object Detection

我们在给第一人称视频做数据质检时，有一条规则是检测并打码视频里的人体纹身。需求很直接：找到纹身区域，生成分割 mask，覆盖上去。这种任务，正常流程是找个现成模型测一下，能用就上，不行再想别的。

规则 7（屏幕检测）和规则 8（裸露检测）都是这么走下来的，现成模型调调阈值就上线了。我以为纹身也差不多。

事实不是这样的。

找到了一个看起来不错的模型

HuggingFace 上有个 jun710/deep-tattoo-yolov8，MIT 协议，YOLOv8s-seg 架构，有分割输出，ultralytics 直接加载，v3 权重只有 23MB。看着完全符合要求，加载进来测。

测试用的是含颈部花卉纹身和手臂纹身的真人第一人称视频。

现象 数据
浅色小臂纹身 偶尔能检到（conf 0.75~0.82）
颈部纹身、深色皮肤纹身 大量漏检，t=150 帧清晰可见却 0 检出
误检 频繁把鞋子、头发、画面角落标成纹身
conf 分布 真纹身 0.33~0.82 与误检 <0.5 重叠，无法用阈值切开
打码定位 conf 0.82 的框打在头部，不在纹身上

conf 分布重叠是最致命的一条。如果真纹身的置信度普遍高于误检，还能调个阈值凑合用。但这里两组分布深度交叠：调高阈值漏真纹身，调低阈值误检爆炸，没有合理的操作点。

根因：三重 OOD 叠加

deep-tattoo 和几乎所有公开纹身模型，训练数据都是”标准摆拍”，正面、好光照、固定距离、展示给镜头看的纹身。

我们的场景叠了三层偏移：

  1. 第一人称俯视角：拍摄者从上往下看自己的手臂，视角在训练分布里几乎不存在
  2. 颈部纹身：俯视时颈部出现变形和遮挡，与正面摆拍差异极大
  3. 深色皮肤：纹身与皮肤的色差本来就小，深色皮肤进一步压缩这个信号

纹身本身的类内方差就极大，图案、颜色、部位千变万化，任何一个训练集的覆盖都是有限的。三重 OOD 叠加之后，模型基本在做随机猜测，漏检的恰好是最需要检出的那些情况。

穷尽了所有替代方向

我们没有只测 deep-tattoo 就放弃，把能想到的路都走了一遍：

方向 结论
jun710 的 U-Net 版（Dice 90%） 仅 189 张训练图、无公开推理代码、同样 OOD
Roboflow / UMass 纹身模型 全正面摆拍训练，对我们场景没有优势
YOLOE / Grounding DINO 开放词汇 本地 CLIP 装不上；纹身零样本召回本来就低
SAM2 只能精细化已有检测框，解决不了漏检根本
PiiBlur 商业 API 底层对本场景的召回未知，且引入外部依赖
2025~26 最新研究 不存在第一人称纹身检测相关工作

SAM2 那条值得单说。SAM2 做分割本来很强，但它是分割工具，不是检测器，需要一个初始框或点作为 prompt。我们的问题是检测漏了，SAM2 只能精化已经检到的东西，无法凭空找到漏检的纹身。开放词汇检测器（YOLOE / Grounding DINO）也试了，纹身这个概念在视觉上太模糊，零样本效果同样差。

和规则 7/8 的对比

同一个质检框架里，之前做的两条规则现成模型都能用：

规则 7 屏幕检测（HaS） 规则 8 裸露检测（NudeNet） 规则 9 纹身检测（deep-tattoo）
现成模型能用吗 可用 可用 不可用，需微调
难点 白墙假阳性 困难样本漏检 类内方差极大 + OOD

区别在哪？屏幕和人体裸露的类内方差小：屏幕就是屏幕，形状颜色相对固定；裸露检测的目标类别也是有限的几种。纹身的类内方差极大，图案可以是任何东西，颜色无限，部位分散在全身。这种目标，现成模型的泛化性能天然脆弱，遇到哪怕一点分布偏移就容易崩掉。

唯一可行路径：微调

调研结论是没有捷径，只有微调。

微调完成后，tattoo_benchmark.py 换 --model 参数直接接入，脚本和流程已经就绪。这条路的成本是确定的，不再是”试试看能不能用”的状态。

这篇记录的价值不在于方案成功，而在于把”现成模型全部行不通”这个结论走到了实测层面。”以为模型应该能用，上线后才发现大量漏检”这个坑，是真实存在的，不是杞人忧天。

收获

  • Conf 分布重叠是调参失败的早期信号。一旦两类置信度范围深度交叠，不要继续调阈值，直接考虑下一层方案
  • SAM2 是分割工具不是检测器，漏检问题靠它解决不了，不要混淆两者
  • 类内方差极大的目标（纹身、艺术字、特殊图案）不要对现成模型抱期望，从一开始就把微调成本纳入计划
  • 测一个场景要专门测最难的子集，不要只测容易案例就下可用结论。这次颈部+深色皮肤+俯视恰好是三重叠加，任何一层单独都不足以揭露问题
  • “现成模型不行”本身是有价值的结论，值得记录，避免以后重走调研路
